# Independent 80% measurement-list comparison

Run `python franka-list/reproduce.py --audit` from the repository root using Python 3.13, NumPy 2.5.2 and SciPy 1.18.1. Omit `--audit` to replay only the policy comparisons. Run with assertions enabled. No service credentials, model calls or simulator installation are needed. The program uses a temporary directory, verifies that all 128 ranking files match the pre-overhead seals, and compares the five recalculated CSV files byte for byte. The optional physical audit independently checks 1,920 successful requests, 1,921 attempts and 1,280 released endpoints.

The 64 archives each contain one independent batch of five parts, both models' inputs and actions, two placement branches from each grasp checkpoint, traces, final images and geometry. Source, calibration, model and randomization seeds, and the locked sample size and stopping rule are in source.tar.gz. Archive metadata is normalized. The one timeout message is redacted to its failure class. Input images, successful model replies, branch receipts and the locked policy are preserved. The 80% quota corresponds to four extra overhead RGB views per five starts. The full paired acquisition observed both potential placements for every part. No physical hardware was used.

results/arms.csv contains the six counts per model. effects.csv gives extra seats per 100 starts with intervals paired by batch, including simultaneous intervals for the two primary contrasts. parts.csv lists all model-specific paired outcomes. batch.csv and overlap.csv contain independent-batch outcomes and list overlap. examples.json and examples/ identify the paired cases. To regenerate the case panels with Pillow, first place results/parts.csv under a writable output directory, then run `python franka-list/select_examples.py OUTPUT franka-list/archives`. Use sizing.py with the earlier franka-transfer/results/decisions.csv to repeat the historical size calculation.

To regenerate the paper figure from the images and paired released heights, install Matplotlib and Pillow and run `python franka-list/plot_cases.py franka-list-cases.pdf`.
