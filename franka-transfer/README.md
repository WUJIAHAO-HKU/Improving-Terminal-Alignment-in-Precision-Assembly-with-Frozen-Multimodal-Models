# Four-fixture Franka transfer in simulation

From the repository root run `python franka-transfer/reproduce.py` (Python 3.8+, standard library). The script reads the recorded scene-level decisions and paired endpoints, checks batch sizes and quotas, computes the conditional one-sided lower bounds and prints both action-selection counts on the identical measured lists. It also reads the receipts for the named paired examples.

For the independent physical audit run `python franka-transfer/independent_check.py` in an environment with NumPy and SciPy. It reads the 20 batch archives, rederives both physical labels from contacts, pose, geometry and stability, checks image hashes, checkpoints, model replies, rankings and gates, and compares the rederived statistics with the exported CSVs. Use `python franka-transfer/plot_cases.py cases.pdf` (Matplotlib and Pillow) to regenerate the manuscript's simulation endpoint figure.

Each batch archive preserves recorded inputs, responses, checkpoints, traces, terminal frames and branch receipts for five scenes and both models. Frozen sources and public calibration are in archives/frozen-source.tar.gz. Core analysis exports are in results/. The records/ directory duplicates the two photographed endpoints for each of four named examples for convenient inspection. The run contains 100 unique scenes and 200 model-specific grasps. Offline paired acquisition made 600 calls. Formal episodes retain trajectories and frames. No real robot or measured production time is involved.

Release copies replace private host, path and calibration identifiers; archive metadata and dependent file checksums were regenerated. The internal commissioning protocol PDF is omitted from the frozen-source mirror; the protocol settings are in formal/freeze.json and the prior stage's public handoff.
